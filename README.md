# deepidv-sdk-ts

Official TypeScript SDKs for the deepidv identity verification platform. Scan IDs, match faces, estimate age, and run full verification flows from any JS/TS runtime.

AI agents registered in getai.id Agent Pay connect to the Agent Pay MCP endpoint with `@deepidv/server/agentPay` (`createAgentPayMcpClient`, `createDpopFetch`); the [Agent Pay guide](docs/guides/AGENT-PAY.md) has the TypeScript client, the Python `DPoPAuth` snippet and the Claude Code `headersHelper` script.
